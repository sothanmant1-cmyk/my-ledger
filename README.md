# My Ledger

A personal expense, budget and to-do app. Works offline. Your data stays on your own device (browser storage), never in this repo.

## Put it online (GitHub Pages)
1. Upload all these files to a new GitHub repo.
2. Repo Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. After a minute your app is live at https://YOUR-USERNAME.github.io/REPO-NAME/

## Install on your phone
- Android (Chrome): open the link → menu (⋮) → Install app.
- iPhone (Safari): open the link → Share → Add to Home Screen.
